# Typing / Translation Game (Unity)

3D typing hra: píšeš slová (EN ↔ SK), postava skočí, kamera pomaly stúpa — kto píše pomaly, umiera. Školský projekt, raný prototyp.

- **Engine:** Unity `6000.6.5f1` · URP · nový Input System · TextMeshPro
- **Build target:** Windows + Linux
